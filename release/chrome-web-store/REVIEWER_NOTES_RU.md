# Инструкция модератору Chrome Web Store

## Проверка основной функции

1. Установите расширение и откройте popup.
2. Нажмите «Присоединиться через Telegram» или «У меня уже есть аккаунт».
3. Отсканируйте показанный QR-код либо откройте ссылку Telegram и подтвердите привязку в боте `@virgo1vpn_bot`.
4. Вернитесь в расширение. Для нового аккаунта активируется пробный период, поэтому покупать подписку для проверки подключения не требуется.
5. Нажмите «Подключиться». Статус и таймер подключения изменятся, а трафик браузера будет направлен через доступную ноду Virgo.
6. Нажмите «Остановить», чтобы удалить настройки прокси.

## Дополнительные экраны

- Кнопка Telegram открывает бота.
- Кнопка `?` открывает раздел поддержки бота.
- «Тарифы» показывает доступные планы; переход к Lava выполняется только после согласия с документами и ввода email для чека.
- Ручной выбор ноды доступен при активной платной подписке; в пробном режиме используется автоматический выбор.

## Пояснение чувствительных разрешений

`proxy`, `webRequest`, `webRequestAuthProvider` и `<all_urls>` нужны только для применения HTTPS-прокси и ответа на запрос авторизации назначенной ноды. Расширение не анализирует и не хранит посещённые адреса или содержимое страниц. Удалённый исполняемый код не используется.
