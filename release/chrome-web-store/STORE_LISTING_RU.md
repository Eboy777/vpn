# Virgo VPN — карточка Chrome Web Store

## Название

Virgo VPN

## Краткое описание

Защищённое подключение браузера через HTTPS-прокси Virgo с выбором доступного сервера.

## Полное описание

Virgo VPN направляет HTTP- и HTTPS-трафик браузера через защищённые прокси-серверы Virgo.

В расширении можно:

- подключить аккаунт через Telegram;
- включить и выключить защищённое подключение;
- автоматически выбрать доступный сервер;
- выбрать конкретный сервер при активной платной подписке;
- посмотреть срок доступа и перейти к выбору тарифа;
- открыть поддержку в Telegram.

Пробный период позволяет проверить подключение перед покупкой. Подписка оформляется на внешней платёжной странице Lava. Virgo VPN действует только внутри браузера и не является системным VPN для всех приложений устройства.

Virgo VPN не записывает посещённые сайты, DNS-запросы и содержимое передаваемого трафика. Для работы сервиса, защиты от злоупотреблений и диагностики используются только необходимые учётные и технические данные в соответствии с политикой конфиденциальности.

Поддержка: virgovpncare@proton.me

Предоставить пользователю управляемое защищённое подключение трафика браузера через HTTPS-прокси Virgo и показать состояние доступа к этому подключению.
