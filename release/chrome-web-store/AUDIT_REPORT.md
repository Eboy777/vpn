# Предрелизный аудит Virgo VPN 1.0.0

## Проверено

- Manifest V3, версия, иконки, service worker и popup.
- Соответствие каждого permission фактической функции расширения.
- Обоснованность `<all_urls>` для авторизации HTTPS-прокси на произвольных сайтах.
- Отсутствие удалённого исполняемого кода, `eval`, динамической загрузки скриптов и встроенных секретов.
- Production-адреса control API, Telegram и юридических документов.
- Состав архива: только runtime-файлы, без тестов, документации и исходных макетов.
- Соответствие фактически собираемых данных опубликованной политике: Telegram ID, IP и ограниченные технические данные раскрыты; посещённые сайты, DNS и содержимое трафика не заявлены и расширением не собираются.
- Экран выбора серверов с пятью нодами: список прокручивается, каждая нода отображается отдельной кнопкой, последняя нода доступна и выбирается.

## Итог

Блокирующих проблем для отправки пакета в Chrome Web Store по проверенной области не обнаружено. Широкий host permission оставлен осознанно: без него браузер не передаст расширению запрос авторизации прокси для произвольного открываемого сайта.
